# Business Manager — Требования к продукту

## Описание проекта

**Business Manager** — мобильное Flutter-приложение для одного владельца малого бизнеса.

Стек технологий:
- Flutter + Dart
- Provider (state management)
- SQLite (sqflite) — локальная база данных
- SharedPreferences — настройки
- fl_chart — графики
- intl — форматирование

Backend (уже настроен):
- MongoDB через .env переменные (опционально, основная логика — локально)
- JWT аутентификация

## Бизнес-правила

1. Стоимость заказа ≠ полученные деньги
2. Платёж создаёт транзакцию автоматически
3. Не допускать двойного учёта одного платежа
4. Транзакция принадлежит месяцу своей даты
5. Исторические данные не изменяются при смене периода
6. Безопасные денежные вычисления (integer cents)
